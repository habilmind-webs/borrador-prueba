# Plantilla de borrador de web (Habilmind)

1. «Use this template» → nuevo repo en **habilmind-webs** llamado `borrador-<nombre>` (minúsculas, números y guiones).
2. Edita, haz commit y push a `main`. En ~2–4 minutos sale en `https://borrador-<nombre>.2-31-95-201.sslip.io`.
3. Esmarelda recibe aviso de revisión (lista en `REVISION.md`).
4. El dominio real solo con el OK de Joaquín.

Guía completa: `BORRADORES-COMO-USAR.md` (webs-habilmind).
